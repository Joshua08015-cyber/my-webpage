# Personal Portfolio Website

## About the Project

This project is a simple personal portfolio webpage created to showcase
a developer's profile, skills, and projects.

The website includes:

- Home section
- About section
- Skills section
- Projects section
- Contact section
- Responsive design
- Interactive navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## AI Tool Used

ChatGPT was used to help create and improve this webpage.

## How AI Helped

ChatGPT helped me generate the initial webpage structure and provided
suggestions for the HTML, CSS, and JavaScript.

AI was also used to help improve the website's styling, navigation,
responsive design, and overall user experience.

I then edited, tested, and improved the webpage during development.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional software or dependencies are required.
